Set up YouTube search (owner only, one time)
  1. Go to console.cloud.google.com, log in with Google and make a new project called YouPod.
  2. Open APIs & Services → Library, find YouTube Data API v3 and click Enable.
  3. Open APIs & Services → Credentials → Create credentials → API key.
  4. Click the new key to edit it. Under Application restrictions pick Websites and add . Under API restrictions pick YouTube Data API v3. Click Save.
